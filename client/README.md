# TaskMate AI client

The React and Vite frontend for TaskMate AI. It sends chat messages to the task API and displays the assistant's responses.

Start the client from this directory:

```sh
npm install
npm run dev
```

By default, the client uses `http://127.0.0.1:5000` for the API. Set `VITE_API_BASE_URL` in `client/.env` to override it.

For full setup instructions, environment configuration, and the MCP workflow, see the [project README](../README.md).
